Contact Management System

A desktop contacts app in Python. Stores names and phone numbers in SQLite and searches them through in-memory indexes, using a Tkinter interface.
----
Features:
----

-Add, edit, view and delete contacts, stored in a local SQLite database

-Search by name, matching any word in it — forename or surname

-Search by phone number, ignoring spaces, dashes, brackets and country codes

-Contacts always listed alphabetically, regardless of entry order

-Refuses a phone number already saved against another contact

-Warns before saving a name that another contact already has

Requires Python 3.6 or later with Tkinter
